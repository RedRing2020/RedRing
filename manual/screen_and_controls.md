# 画面と操作

## 画面の構成

| 部分 | 内容 |
|---|---|
| メニューバー | 「ファイル」→「読み込み…」で形状ファイル（当面は STL）を読み込みます。STL ファイルをウィンドウにドロップしても読み込めます。「表示」→「言語」で画面の文言の言語を選びます。「ヘルプ」→「操作の一覧」でキーの一覧を、「バージョンの情報」で版・ログのファイルの場所・マニュアルへのリンクを出します |
| モデル表示画面 | 製品形状・素材・ツールパスの線・工具の線を表示します |
| 左上の進捗バー | 切削シミュレーションを取り込むと出ます。左ドラッグで、任意の時点へ移せます（スクラブ） |
| 画面の下のステータスバー | 最後のメッセージを 1 行で出します。形状の読み込み・投入・実行・取り込みの結果と、操作できなかったときの理由です。注意は黄色、失敗は赤で出します |
| ウィンドウのタイトル | 切削シミュレーションを取り込むと、今の時点（`Snapshot 1/N`）・区間の番号・残りの体積・再生の倍率を出します |

画面の文言は、日本語と英語から「表示」→「言語」で選べます（初めは日本語）。選ぶとすぐに替わり、次に起動したときも同じ言語になります。選んだ言語は、利用者ごとの設定のファイル（Windows では `%APPDATA%\RedRing\settings.json`）に保存します。ログの文言は、画面の言語にかかわらず英語です。

## ウィンドウ

| ウィンドウ | 開き方 | 内容 |
|---|---|---|
| 加工条件のウィンドウ | `Shift+M` | 工具・加工・素材の条件の入力と、切削シミュレーションの投入・取り込み（[切削シミュレーション](./cutting_simulation_demo.md)） |
| 操作の一覧 | `F1`・`h`、または「ヘルプ」→「操作の一覧」 | キーとマウスの操作の一覧（下の「キーの割り当て一覧」と同じ） |
| 設定パネル | `Shift+S` | 表示の設定。タブは「表示」（コマ送りの移動量・切削アニメーションの色・削り込みの色分け）、「工具」（工具の線の分割数・ツールパスの表示）、「デバッグ」（デバッグ用の表示） |

設定パネル・加工条件のウィンドウの入力欄を編集している間は、打った文字はキー操作になりません（`Esc` キーでの終了を除く）。

## カメラ

| 操作 | 内容 |
|---|---|
| `Ctrl+左ドラッグ` | 回転 |
| `Ctrl+中ドラッグ` | パン |
| `Ctrl+右ドラッグ` または `Ctrl+ホイール` | ズーム |
| `r` | カメラをリセット（形状に合わせ直す） |
| `t` | 標準 CAD 視点 |
| `f` | 正面視点 |
| `e` | 緊急脱出（めり込んだカメラを戻す） |

## キーの割り当て一覧

`F1`・`h` キーで開く「操作の一覧」のウィンドウと同じです。

| 分類 | キー | 操作 |
|---|---|---|
| カメラ | `r` | カメラをリセット |
| | `t` | 標準 CAD 視点 |
| | `f` | 正面視点 |
| | `e` | 緊急脱出（めり込んだカメラを戻す） |
| 切削シミュレーション | `Shift+M` | 加工条件のウィンドウの表示・非表示（「投入」で投入） |
| | `Shift+R` | キューにあるジョブを実行 |
| | `Shift+L` | 今の条件で計算した最も新しい切削シミュレーションを取り込み |
| | `k` / `j` | コマ送りの移動量だけ進む / 戻る |
| | `.` / `,` | 工具を次 / 前の区間の端点へ移す |
| | `Space` | 自動再生 / 一時停止 |
| | `Shift+J` | 自動再生を停止して先頭へ |
| | `+` / `-` | 再生速度を 2 倍 / 半分 |
| 表示 | `w` | ソリッド表示 / ワイヤーフレーム表示 |
| | `v` | ツールパスの線の表示・非表示 |
| | `Shift+V` | 工具の線の表示・非表示 |
| アプリ | `Shift+S` | 設定パネルの表示・非表示 |
| | `F1` / `h` | 操作の一覧のウィンドウの表示・非表示 |
| | `Esc` | 終了 |

- `w`: ソリッド表示とワイヤーフレーム表示（三角形の辺）を切り替えます
- `v`: ツールパスの線は素材の面を通して全部見えるため、素材の削れ方を見るときは非表示にします
- 表示・非表示の状態は、コマ送り・自動再生・取り込み・「設定を反映」の後も保ちます

## デバッグ用の表示

線分・円・円弧・三角形と、逆オフセット形状のデバッグ用の表示は、キーではなく、設定パネル（`Shift+S`）のデバッグタブのボタンから表示します。

デバッグタブの「逆オフセット形状」の「表示」は、表示中の製品形状と計算条件の工具で、ツールパス生成と同じ逆オフセット形状を作り、要素を役割ごとの色で表示します（製品形状は表示しません。計算条件に誤りがある場合は表示しません）。

| 色 | 要素 |
|---|---|
| 黄 | 高さを求める面（上を向く面） |
| 青 | 高さを求めない面（鉛直な面・アンダーカットの面を、外向きにずらしたもの） |
| 紫 | 開いた形の下を向く面を、上側にずらしたもの |
| 赤 | 外（材料のない側）を決められなかった形の面 |
| 緑 | 頂点（ボール: 球面、フラット: 工具の底が乗る頂点だけ円板） |
| 水色 | 辺（ボール: 円柱面、フラット: 円板の縁を辺に沿って動かした形のうち、辺に接する部分） |

球面・円柱面・円板は 10° のきざみで三角形に分けて表示します（表示だけに使い、計算には使いません）。
