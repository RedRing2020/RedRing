# 画面と操作

## 画面の構成

| 部分 | 内容 |
|---|---|
| メニューバー | 「ファイル」で、モデルファイルの新規・開く・保存・名前を付けて保存と、形状ファイルの読み込み・終了を行います（下の「モデルファイル」）。「加工」で、加工手順を開く・閉じると、工程リストの表示・非表示と、工程の設定・手順の設定のダイアログを開くことを行います（[切削シミュレーション](./cutting_simulation_demo.md)）。「表示」→「言語」で画面の文言の言語を選びます。「ヘルプ」→「操作の一覧」でキーの一覧を、「バージョンの情報」で版・ログのファイルの場所・マニュアルへのリンクを出します |
| モデル表示画面 | 製品形状・素材・ツールパスの線・工具の線を表示します。メニューバーと、工程リスト・ステータスバーの間に描きます（見る中心と回転の中心は、その間の中心です。工程リストの高さを変えても、拡大縮小率は変わりません。形状を読み込んだときなどに全体に合わせるときは、その間に収まるように合わせます） |
| 左上の進捗バー | 切削シミュレーションを取り込むと出ます。左ドラッグで、任意の時点へ移せます（スクラブ） |
| 画面の下のステータスバー | 最後のメッセージを 1 行で出します。形状の読み込み・投入・実行・取り込みの結果と、操作できなかったときの理由です。注意は黄色、失敗は赤で出します。長い文は 1 行に収めて切り詰めます。左の 📋 を押すと、最近のメッセージ（新しい順・全文。文字を選んで写せます）と、加工手順を開いているときは選んだ工程の状態（計算の状態・空間モデルの CL の状態・条件の誤り）の一覧を開きます。まだ一覧を開いていない注意・失敗があると、📋 を黄色・赤で出します |
| ウィンドウのタイトル | 開いているモデルファイルの名前を出します（まだ保存していなければ「無題」）。保存していない変更があるときは、名前の後ろに `*` を付けます。切削シミュレーションを取り込むと、今の時点（`Snapshot 1/N`）・区間の番号・残りの体積・再生の倍率を出します |

## モデルファイル

製品形状と、加工手順・加工工程（加工の条件・素材）を、1 つのモデルファイル（拡張子 `.rrm`）に保存し、開き直せます。1 つのウィンドウで 1 つのモデルファイルを扱います。

| 「ファイル」の項目 | キー | 内容 |
|---|---|---|
| 新規 | `Ctrl+N` | 空の空間モデルにします（加工の条件は初めの値に戻ります） |
| 開く… | `Ctrl+O` | モデルファイルを選んで開きます。今の空間モデルと置き換わります |
| 保存 | `Ctrl+S` | 開いているモデルファイルに保存します。まだ保存していなければ、名前を付けて保存と同じです |
| 名前を付けて保存… | `Ctrl+Shift+S` | ファイルを選んで保存します。以後はそのファイルに保存します |
| 読み込み… | | 形状ファイル（当面は STL）を読み込み、今の空間モデルに加えます |
| 終了 | | アプリを終えます |

- ウィンドウにファイルをドロップすると、モデルファイルは「開く」と同じに、STL ファイルは「読み込み…」と同じに扱います
- 保存していない変更（形状の読み込み、加工の条件・素材の変更）があるときに、新規・開く・終了（ウィンドウの閉じるボタン・`Esc` キーを含む）をすると、保存するかを確かめます。「保存する」で保存してから続け、「保存しない」で変更を捨てて続け、「やめる」で何もしません
- モデルファイルを開き直すと、前に投入した計算の結果を、そのまま取り込めます（ジョブマネージャーに結果が残っている間）
- 同じモデルファイルを 2 つのアプリで開いて両方で保存すると、後から保存したほうが残ります
- 新しい版のアプリで保存したモデルファイルは、開けないことがあります（開けない理由をステータスバーに出します）

画面の文言は、日本語と英語から「表示」→「言語」で選べます（初めは日本語）。選ぶとすぐに替わり、次に起動したときも同じ言語になります。選んだ言語は、利用者ごとの設定のファイル（Windows では `%APPDATA%\RedRing\settings.json`）に保存します。ログの文言は、画面の言語にかかわらず英語です。

## ウィンドウ

| ウィンドウ | 開き方 | 内容 |
|---|---|---|
| 工程リスト（画面の下） | 「加工」→「加工手順を開く」。開いている間は `Shift+M`・「加工」→「工程リスト」で表示・非表示 | 加工手順の工程の表と、切削シミュレーションの投入・取り込み（[切削シミュレーション](./cutting_simulation_demo.md)） |
| 工程の設定（ダイアログ） | 工程リストの行のダブルクリック・右クリックのメニュー・「工程の設定」、または「加工」→「工程の設定」 | 選んだ工程の工具・加工の条件の入力（「適用」で工程に入れます） |
| 手順の設定（ダイアログ） | 工程リストの「手順の設定」、または「加工」→「手順の設定」 | 加工手順の素材（余裕・精度）の入力（「適用」で手順に入れます） |
| 操作の一覧 | `F1`・`h`、または「ヘルプ」→「操作の一覧」 | キーとマウスの操作の一覧（下の「キーの割り当て一覧」と同じ） |
| 設定パネル | `Shift+S` | 表示の設定。タブは「表示」（コマ送りの移動量・切削アニメーションの色・削り込みの色分け）、「工具」（工具の線の分割数・ツールパスの表示）、「デバッグ」（デバッグ用の表示） |

設定パネル・設定のダイアログの入力欄を編集している間は、打った文字はキー操作になりません（`Esc` キーでの終了を除く）。

## カメラ

| 操作 | 内容 |
|---|---|
| `Ctrl+左ドラッグ` | 回転 |
| `Ctrl+中ドラッグ` | パン（見えている形がマウスに付いて動きます。拡大縮小しても同じです） |
| `Ctrl+右ドラッグ` または `Ctrl+ホイール` | ズーム |
| `r` | カメラをリセット（形状に合わせ直す） |
| `t` | 標準 CAD 視点 |
| `f` | 正面視点 |
| `e` | 緊急脱出（めり込んだカメラを戻す） |

## キーの割り当て一覧

`F1`・`h` キーで開く「操作の一覧」のウィンドウと同じです。

| 分類 | キー | 操作 |
|---|---|---|
| カメラ | `r` | カメラをリセット |
| | `t` | 標準 CAD 視点 |
| | `f` | 正面視点 |
| | `e` | 緊急脱出（めり込んだカメラを戻す） |
| 切削シミュレーション | `Shift+M` | 加工手順を開いている間、工程リストの表示・非表示（「投入」で投入） |
| | `Shift+L` | 加工手順を開いている間、今の条件で計算した最も新しい切削シミュレーションを取り込み |
| | `k` / `j` | コマ送りの移動量だけ進む / 戻る |
| | `.` / `,` | 工具を次 / 前の区間の端点へ移す |
| | `Space` | 自動再生 / 一時停止 |
| | `Shift+J` | 自動再生を停止して先頭へ |
| | `+` / `-` | 再生速度を 2 倍 / 半分 |
| 表示 | `w` | ソリッド表示 / ワイヤーフレーム表示 |
| | `v` | ツールパスの線の表示・非表示 |
| | `Shift+V` | 工具の線の表示・非表示 |
| アプリ | `Ctrl+N` | 新しい空間モデル |
| | `Ctrl+O` | モデルファイルを開く |
| | `Ctrl+S` | 保存 |
| | `Ctrl+Shift+S` | 名前を付けて保存 |
| | ファイルをドロップ | モデルファイルは開き、STL は形状を読み込む |
| | `Shift+S` | 設定パネルの表示・非表示 |
| | `F1` / `h` | 操作の一覧のウィンドウの表示・非表示 |
| | `Esc` | 終了 |

- `w`: ソリッド表示とワイヤーフレーム表示（三角形の辺）を切り替えます
- `v`: ツールパスの線は素材の面を通して全部見えるため、素材の削れ方を見るときは非表示にします
- 表示・非表示の状態は、コマ送り・自動再生・取り込み・「設定を反映」の後も保ちます

## デバッグ用の表示

線分・円・円弧・三角形と、逆オフセット形状のデバッグ用の表示は、キーではなく、設定パネル（`Shift+S`）のデバッグタブのボタンから表示します。デバッグタブの「通常の表示に戻す」で、デバッグ用の表示の前の製品形状・切削アニメーションの表示（同じコマ・同じカメラの向き）に戻ります。デバッグ用の表示の間は、切削アニメーションのコマ送り・自動再生はできません。逆オフセット形状の表示は、カメラの向き・拡大を変えずに描き（その表示で動かしたカメラは、通常の表示に戻した後もそのまま使います）、取り込んだ切削シミュレーションのツールパスの線を重ねます（工具の先端が逆オフセット形状の上面を通るかを確かめられます）。線の表示・非表示は、通常の表示と同じ `v` キーで切り替えます。取り込んだ結果の工具と今の計算条件の工具（種類・半径）が違うと、線は逆オフセット形状に合わないため、ステータスバーで知らせます。

デバッグタブの「逆オフセット形状」の「表示」は、表示中の製品形状と計算条件の工具で、ツールパス生成と同じ逆オフセット形状を作り、要素を役割ごとの色で表示します（製品形状は表示しません。計算条件に誤りがある場合は表示しません）。

| 色 | 要素 |
|---|---|
| 黄 | 高さを求める面（上を向く面） |
| 青 | 高さを求めない面（鉛直な面・アンダーカットの面を、外向きにずらしたもの） |
| 紫 | 開いた形の下を向く面を、上側にずらしたもの |
| 赤 | 外（材料のない側）を決められなかった形の面 |
| 緑 | 頂点（ボール: 球面、フラット: 工具の底が乗る頂点だけ円板） |
| 水色 | 辺（ボール: 円柱面、フラット: 円板の縁を辺に沿って動かした形のうち、辺に接する部分） |

球面・円柱面・円板は 10° のきざみで三角形に分けて表示します（表示だけに使い、計算には使いません）。
