# 既知の制約と困ったとき

## 既知の制約（v0.1.3 プレビュー）

加工:

- NC を出力しません。ツールパスは切削シミュレーションで確かめるためのもので、実際の加工には使えません（NC の出力は v0.3.0 の予定です）
- パスの間のエアカット・つなぎの移動（アプローチ・リトラクト）はありません。切削シミュレーションでは、工具はパスの終わりから次のパスの始まりへ跳び、その間は削りません
- 工具の半径より狭い隙間・穴は、両側を 1 本のパスでつなぎ、隙間の上を切削の送りで通ります（隙間の壁は削り込みません）。工具が形状に接しない所にある、走査線に沿って工具の半径より短く接する小さな形状は見落とし、削り残すことがあります
- NURBS の形状では、三角形に分ける誤差とパスの誤差の合計が、最大でツールパス生成のトレランスの 2 倍になります（STL はトレランスに収まります）
- ツールパス生成のトレランス（0.001 mm）は変えられません
- 工具はボールエンドミル・フラットエンドミルだけです。工具長を指定しても、工具長より上で形状に接する経路をエラーにしません（工具長より上の素材を残すだけです）

管理:

- 加工手順は 1 つです。加工工程は複数持てますが、どの工程の切削シミュレーションも手順の素材から始めます（前の工程の後の素材から始めるのは、後の版です）。工具の登録（ツールライブラリ）はありません（v0.2.0 の予定です）
- ジョブマネージャーは 1 つずつ計算します。アプリを開き直すと、前に投入したジョブの結果を工程から取り込めません（工程の保存は後の版で足します）
- 加工の対象は表示中のすべての製品形状です（面の選択は後続の対応です）
- 取り込むジョブを選ぶ画面はまだなく、取り込みは今の条件の最も新しい結果だけです

配布:

- 配布物は Windows 用だけです。実行ファイルにはまだコード署名がないため、初めて起動するときに Windows の SmartScreen の警告が出ます（確かめ方は [動かす](./getting_started.md) を参照してください）

表示:

- ログの文言は、画面の言語にかかわらず英語です。不具合を報告するときは、そのまま添えてください
- 設定のファイル（Windows では `%APPDATA%\RedRing\settings.json`）を読めないときは、日本語で起動し、画面の下のステータスバーにメッセージを出します。読めなかったファイルは上書きしないため、その間に選んだ言語は次の起動に残りません。ファイルを直すか消してから起動し直してください
- 素材の色（透明度を含む）と工具の線の色は、設定パネル（`Shift+S`）の表示タブの「切削アニメーションの色」で選び、「設定を反映」で表示に反映します。素材は色だけを変え、面は作り直しません。反映するまでは、再生中も前の色で描きます
- 削った面が素材の格子の線をちょうど通る所では、素材の面に小さな隙間ができることがあります
- 素材を半透明にすると、中の製品形状が透けて見えます。半透明の面は奥から手前への並べ替えをしないため、素材の面どうしが重なる所では見え方が乱れることがあります
- 取り込んだ後に設定パネル（`Shift+S`）の工具タブで変えた設定（工具の線の分割数・ToolPath の表示）は、「設定を反映」で、今のコマ・カメラ・表示モードのまま描き直して反映します

## 困ったとき

| 症状 | 確かめること |
|---|---|
| 「CL 取込」「切削シミュレーション取込」で取り込めない | 条件か表示中の製品形状を変えた後は、投入し直すまで取り込めません。加工条件のウィンドウの最後の操作の結果の行と、ログ（`logs/redring.log`）を確かめてください |
| 「投入」を押せない | 条件の誤りが、直す欄の下に赤い文字で出ています。誤りを直すと押せます |
| 「投入」で「ジョブマネージャーがインストールされていない」と出る | アプリと同じフォルダに `redring-job-manager` と `redring-batch-runner` があるか確かめてください。ソースからビルドした場合は `cargo build --release` でビルドします |
| 計算が「計算待ち」のまま進まない | ジョブマネージャーのログ（`%LOCALAPPDATA%\RedRing\jobs\manager.log`）を確かめてください |
| 計算が「失敗しました」になる | ジョブのログ（`%LOCALAPPDATA%\RedRing\jobs\<ジョブの番号>\logs\runner.log`）に理由があります |
| ファイルを開く画面を開いている間、描画が止まる | ファイルを開く画面を閉じると戻ります |
| 素材を回転すると、描画が止まる・画面が消える | 素材の精度が細かい（例えば 0.01 mm）と、GPU の負荷が大きくなり、GPU のデバイスが失われることがあります。そのときはエラーメッセージの画面を出して終わります。精度を粗くして投入し直してください |
| カメラが形状にめり込んだ | `e` キー（緊急脱出）か、`r` キー（リセット）を押します |
| キーが効かない | 設定パネル・加工条件のウィンドウの入力欄を編集している間は、打った文字はキー操作になりません。入力欄の外をクリックしてください |

不具合を報告するときは、[GitHub Issues](https://github.com/RedRing2020/RedRing/issues) に、操作の手順とログのファイル（`logs/redring.log`）を添えてください。
