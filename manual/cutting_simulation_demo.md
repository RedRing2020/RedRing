# 切削シミュレーション 操作

製品形状（STL）を取り込み、表示中の製品形状を加工の対象として切削シミュレーションを投入・実行し、結果を製品形状に重ねて時系列で確認します。

## 現在の対象範囲

- 対応工具: フラットエンドミル、ボールエンドミル（既定はボールエンドミル φ10）。工具長は既定では指定せず、工具より高い位置で接触した素材も除去します。工具長を指定すると、工具長より上の素材は残ります
- 加工: 3 軸の走査線加工（既定はダウンカット・ピックフィード 2 mm・送り 1200 mm/min）。CL の点は走査線に沿って工具の半径以下の間隔で求め、工具が形状に接する所の端はツールパス生成のトレランスまで求めます。CL の点と点の間で工具がツールパス生成のトレランスを超えて製品形状に食い込まないように、必要な所に点を足し、CL の段差では高い側の高さのまま進んでから下ろします。送り方はダウンカット・アップカット・ジグザグ（ダウンカットから始めて線ごとに向きを入れ替える）から選べます。主軸は右回りとして決めます
- 素材: 製品形状を囲む箱の各面（−X・+X・−Y・+Y・上・底）の外側に余裕を足した直方体（既定の余裕は 0。製品形状を囲む箱そのもの）
- 素材の精度: 既定は 0.05 mm（素材の面の細かさを決めます。φ10 の工具で約 1.4 mm 間隔の格子になります）
- スナップショット操作: コマ送り、巻き戻し、スクラブ、自動再生
- 表示モード: ソリッド表示、ワイヤーフレーム表示

工具・加工・素材の計算条件は、加工条件のウィンドウ（Shift+M）で入力し、「投入」で投入します。表示の設定（設定パネル。Shift+S）とは別のウィンドウです。

## 手順

1. ワークスペースのルートで `cargo run` を実行します。
2. メニューバーの「ファイル」→「読み込み…」で STL ファイルを選ぶか、STL ファイルをウィンドウにドロップして、形状を読み込みます。読み込んだ形状は、表示中の製品形状として加工の対象になります。
3. `Shift+M` を押して加工条件のウィンドウを開き、工具・加工・素材の条件を入力して「投入」を押します。表示中の製品形状で切削シミュレーションを投入し、「投入したらすぐ実行する」（既定は入）により続けて実行します（ジョブマネージャーができるまでの操作です。実行が終わるまで画面は止まります）。
4. 「取り込み」を押して、正常に実行済みの切削シミュレーションのうち最も新しいものを取り込みます。

「投入したらすぐ実行する」を外した場合は、`Shift+R` で実行します。`Shift+L` は「取り込み」と同じ操作です。

取り込みに成功すると、以下が表示されます。

- 製品形状と素材の面、ToolPath ライン、工具ライン
- 左上の進捗バー
- ウィンドウタイトル上の現在フレーム情報

取り込んでも、カメラ（向き・拡大）は変えません。条件を変えて取り込み直しても、同じ所を見比べられます。カメラを形状に合わせ直すときは `r` を押します（表示中の製品形状がない場合だけ、取り込んだときに素材に合わせます）。

## 基本操作

### 投入・実行・取り込み

- メニューバーの「ファイル」→「読み込み…」: ファイルを開く画面で形状ファイル（当面は STL）を選んで読み込みます（画面を開いている間は、アプリの描画が止まります）
- STL ファイルをドロップ: 「読み込み…」と同じく読み込みます
- `Shift+M`: 加工条件のウィンドウを開きます。「投入」で表示中の製品形状を投入します
- `Shift+R`: キューにあるジョブを実行します
- `Shift+L`: 最も新しい切削シミュレーションを取り込んで再生できるようにします
- `h`: 利用可能なキー操作をログへ表示します

### 加工条件のウィンドウ

- 工具（種類・工具径・工具長）、加工（送り方・ピックフィード・送り・工具の移動範囲）、素材（余裕・精度）を入力します。ツールパス生成のトレランス（0.001 mm）は表示だけで、変えられません
- 加工の欄に、平らな面で隣り合うパスの間に残る山の高さ（カスプハイト）の上限を表示します（パスの間は、加工範囲を等分するため、ピックフィード以下になります）。ボールエンドミルは工具径とピックフィードで決まり（例: 工具径 10 mm・ピックフィード 2 mm で 0.1010 mm）、フラットエンドミルは 0 です。傾いた面では変わるため、目安の値です。ピックフィードが工具径を超えるときは表示しません
- 条件に誤りがあると、直す欄の下に赤い文字で出し、「投入」を押せなくなります。例: 精度がツールパス生成のトレランスより細かい、素材の大きさに対して精度が細かすぎる（投入できる最も細かい精度を表示します）、ピックフィードが工具径を超える（工具径を表示します）。誤りの文は表示の言語（日本語・英語）で出します。ジョブの実行や結果の取り込みなど、条件では直せない失敗は、文の後に元の理由を英語で添えます
- 「投入」「取り込み」の下に、最後の操作（投入・実行・取り込み）の結果を 1 行で表示します
- 「表示中の結果の条件」には、取り込んだ切削シミュレーションの計算に使った条件（工具・加工・トレランス・素材の大きさ・精度）を表示します

### スナップショット移動

- `k`: コマ送りの移動量だけ経路に沿って進んだフレームへ進みます（最後のフレームからは先頭へ）
- `j`: コマ送りの移動量だけ経路に沿って戻ったフレームへ戻ります（先頭のフレームからは最後へ）
- コマ送りの移動量は、設定パネル（Shift+S）の表示タブの「コマ送り」で mm の数値で入力します。取り込むたびに、ツールパスの全長の 1/100（1 回の送りが進捗バーの約 1%）に戻ります。「初期値に戻す」ボタン（初期値の mm を併記）で、取り込んだ直後の値に戻せます。移動量が 1 フレームの間隔より短い場合（0 を含む）は、1 フレームずつ移ります
- `.` / `,`: 工具を次 / 前の区間の端点（ツールパスの直線の区間の始点・終点）へ移します。素材は、その端点の手前で最も近いフレームの状態を表示します（フレームは工具と格子から決めた間隔で記録するため、端点ちょうどの素材の形はありません）。端点に置いている間は、ウィンドウタイトルに工具の端点の番号と、表示している素材のフレームを表示します。`k`・`j`・スクラブ・自動再生でフレームが変わると、工具はフレームの位置に戻ります
- 左上の進捗バーを左ドラッグ: 任意フレームへスクラブします
- `Space`: 自動再生と一時停止を切り替えます。1 倍では、工具が経路に沿って毎秒 1 m 進みます（どのワークでも、同じ倍率なら工具の速さは同じです）
- `Shift+J`: 自動再生を停止して先頭フレームへ戻します
- `+` / `-`: 再生速度を 2 倍・半分にします（0.25 倍から 32 倍まで）。現在倍率はウィンドウタイトルに表示されます

取り込む前に `k`・`j`・`Space` を押すと、取り込まれていない旨をログへ表示します。

前へ進む場合も戻る場合も、変化した部分の素材の面だけを差し替えます。最初のほうへ大きく戻す場合（末尾で `Space` を押して最初から再生する場合など）は、初期の素材から面を作り直します。

自動再生は、描画が間に合わない区間ではコマを飛ばさずに再生がゆっくりになります。倍率を上げて 1 回の描画で工具が工具の大きさより大きく進むと（たとえば φ10 の工具では 4 倍以上）、画面の描き直しが工具の動きに追いつかず、残像で工具が複数あるように見えます。工具の線は常に描きます。

### 削り込み・削り残しの色分け

最後のフレームでは、素材の面を、製品形状との比較で色分けします（既定は入）。

| 色（既定） | 意味 |
|---|---|
| 赤 | 削り込み（製品形状の内側へ、ツールパス生成のトレランスより深く削った所） |
| 緑 | トレランスの中（製品形状からの距離がトレランス以内） |
| 青 | 削り残し（製品形状の外側へ、トレランスより離れた所） |
| 素材の色 | 比べていない所（削っていない素材の外周など） |

- トレランスは 0.001 mm のため、ボールエンドミルのパスの間の山（カスプハイトの分）は削り残しの色になります。緑は、パスの中心の近くなど、製品形状に届いた所に出ます
- 色は素材の格子の間隔ごとに決めるため、色の境は格子の間隔（精度 0.05 mm で約 1.4 mm）ほどずれることがあり、それより細い削り込みは見落とすことがあります
- 色分けの入・切と 3 つの色は、設定パネル（Shift+S）の表示タブの「切削アニメーションの色」で選び、「設定を反映」で反映します。最後のフレーム以外では、素材の色で描きます

### 表示切替

- `w`: ソリッド表示とワイヤーフレーム表示（三角形の辺）を切り替えます
- `v`: ツールパスの線の表示・非表示を切り替えます。ツールパスの線は素材の面を通して全部見えるため、素材の削れ方を見るときは非表示にします
- `Shift+V`: 工具の線の表示・非表示を切り替えます
- 表示・非表示の状態は、コマ送り・自動再生・取り込み・「設定を反映」の後も保ちます

### カメラ操作

- `Ctrl+左ドラッグ`: 回転
- `Ctrl+中ドラッグ`: パン
- `Ctrl+右ドラッグ` または `Ctrl+ホイール`: ズーム

## キーの割り当て一覧

h キーでログに出す一覧と同じです。設定パネル・加工条件のウィンドウの入力欄を編集している間は、打った文字はキー操作になりません（Esc キーでの終了を除く）。

| 分類 | キー | 操作 |
|---|---|---|
| カメラ | `r` | カメラをリセット |
| | `t` | 標準 CAD 視点 |
| | `f` | 正面視点 |
| | `e` | 緊急脱出（めり込んだカメラを戻す） |
| 切削シミュレーション | `Shift+M` | 加工条件のウィンドウの表示・非表示（「投入」で投入） |
| | `Shift+R` | キューにあるジョブを実行 |
| | `Shift+L` | 最も新しい切削シミュレーションを取り込み |
| | `k` / `j` | コマ送りの移動量だけ進む / 戻る |
| | `.` / `,` | 工具を次 / 前の区間の端点へ移す |
| | `Space` | 自動再生 / 一時停止 |
| | `Shift+J` | 自動再生を停止して先頭へ |
| | `+` / `-` | 再生速度を 2 倍 / 半分 |
| | `w` | ソリッド表示 / ワイヤーフレーム表示 |
| | `v` / `Shift+V` | ツールパスの線 / 工具の線の表示・非表示 |
| アプリ | `Shift+S` | 設定パネルの表示・非表示 |
| | `h` | キーの一覧をログへ表示 |
| | `Esc` | 終了 |

線分・円・円弧・三角形・NURBS・逆オフセットの包絡面・Octree・ツールパスだけの表示などのデバッグ用の表示は、キーではなく、設定パネル（Shift+S）のデバッグタブのボタンから表示します。

デバッグタブの「逆オフセット形状」の「表示」は、表示中の製品形状と計算条件の工具で、ツールパス生成と同じ逆オフセット形状を作り、要素を役割ごとの色で表示します（製品形状は表示しません。計算条件に誤りがある場合は表示しません）。

| 色 | 要素 |
|---|---|
| 黄 | 高さを求める面（上を向く面） |
| 青 | 高さを求めない面（鉛直な面・アンダーカットの面を、外向きにずらしたもの） |
| 紫 | 開いた形の下を向く面を、上側にずらしたもの |
| 赤 | 外（材料のない側）を決められなかった形の面 |
| 緑 | 頂点（ボール: 球面、フラット: 工具の底が乗る頂点だけ円板） |
| 水色 | 辺（ボール: 円柱面、フラット: 円板の縁を辺に沿って動かした形のうち、辺に接する部分） |

球面・円柱面・円板は 10° のきざみで三角形に分けて表示します（表示だけに使い、計算には使いません）。

## 取り込み直後に確認するポイント

- ウィンドウタイトルが `Snapshot 1/N` 形式に変わる
- 左上に進捗バーが出る
- `k` / `j` でフレーム番号と残体積が変化し、素材の面が削れていく
- `w` でソリッド表示とワイヤーフレーム表示が切り替わる
- `v` でツールパスの線、`Shift+V` で工具の線が消え、もう一度押すと元に戻る

## 既知の制約（v0.1.0 プレビュー）

加工:

- NC を出力しません。ツールパスは切削シミュレーションで確かめるためのもので、実際の加工には使えません（NC の出力は v0.3.0 の予定です）
- パスの間のエアカット・つなぎの移動（アプローチ・リトラクト）はありません。切削シミュレーションでは、工具はパスの終わりから次のパスの始まりへ跳び、その間は削りません
- 工具の半径より狭い隙間・穴は、両側を 1 本のパスでつなぎ、隙間の上を切削の送りで通ります（隙間の壁は削り込みません）。工具が形状に接しない所にある、走査線に沿って工具の半径より短く接する小さな形状は見落とし、削り残すことがあります
- NURBS の形状では、三角形に分ける誤差とパスの誤差の合計が、最大でツールパス生成のトレランスの 2 倍になります（STL はトレランスに収まります）
- ツールパス生成のトレランス（0.001 mm）は変えられません
- 工具はボールエンドミル・フラットエンドミルだけです。工具長を指定しても、工具長より上で形状に接する経路をエラーにしません（工具長より上の素材を残すだけです）

管理:

- 工程を持たず、投入のたびに加工条件のウィンドウの条件を登録します。工具の登録（ツールライブラリ）もありません（v0.2.0 の予定です）
- ジョブは同じプロセスの中で実行し、実行が終わるまで画面は止まります
- 加工の対象は表示中のすべての製品形状です（面の選択は後続の対応です）
- 投入・実行・取り込みの選択の画面はまだなく、取り込みは最も新しい結果だけです

表示:

- 素材の色（透明度を含む）と工具の線の色は、設定パネル（Shift+S）の表示タブの「切削アニメーションの色」で選び、「設定を反映」で表示に反映します。素材は色だけを変え、面は作り直しません。反映するまでは、再生中も前の色で描きます
- 削った面が素材の格子の線をちょうど通る所では、素材の面に小さな隙間ができることがあります
- 素材を半透明にすると、中の製品形状が透けて見えます。半透明の面は奥から手前への並べ替えをしないため、素材の面どうしが重なる所では見え方が乱れることがあります
- 取り込んだ後に設定パネル（Shift+S）の工具タブで変えた設定（工具の線の分割数・ToolPath の表示）は、「設定を反映」で、今のコマ・カメラ・表示モードのまま描き直して反映します
