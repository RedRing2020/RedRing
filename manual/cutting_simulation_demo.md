# 切削シミュレーション

製品形状（STL）を取り込み、表示中の製品形状を加工の対象として切削シミュレーションを計算し、結果を製品形状に重ねて時系列で確かめます。キーとマウスの操作は [画面と操作](./screen_and_controls.md)、既知の制約は [既知の制約と困ったとき](./known_issues.md) を参照してください。

## 現在の対象範囲

- 対応工具: フラットエンドミル、ボールエンドミル（既定はボールエンドミル φ10）。工具長は既定では指定せず、工具より高い位置で接触した素材も除去します。工具長を指定すると、工具長より上の素材は残ります
- 加工: 3 軸の走査線加工（既定はダウンカット・ピックフィード 2 mm・送り 1200 mm/min）。CL の点は走査線に沿って工具の半径以下の間隔で求め、工具が形状に接する所の端はツールパス生成のトレランスまで求めます。CL の点と点の間で工具がツールパス生成のトレランスを超えて製品形状に食い込まないように、必要な所に点を足し、CL の段差では高い側の高さのまま進んでから下ろします。送り方はダウンカット・アップカット・ジグザグ（ダウンカットから始めて線ごとに向きを入れ替える）から選べます。主軸は右回りとして決めます。走査線の向きは、X 軸から反時計回りの角度（既定は 0°。X 方向の走査線）で決めます。走査線が急な壁に沿う向きでは、壁の上でパスの間隔が広がって削り残しが大きくなるため、主な壁を横切る角度を選びます
- 素材: 製品形状を囲む箱の各面（−X・+X・−Y・+Y・上・底）の外側に余裕を足した直方体（既定の余裕は 0。製品形状を囲む箱そのもの）
- 素材の精度: 既定は 0.05 mm（素材の面の細かさを決めます。φ10 の工具で約 1.4 mm 間隔の格子になります）
- スナップショット操作: コマ送り、巻き戻し、スクラブ、自動再生
- 表示モード: ソリッド表示、ワイヤーフレーム表示

工具・加工の計算条件は工程の設定のダイアログで、素材は手順の設定のダイアログで入力して「適用」し、画面の下の工程リストの「計算」で計算します。工程リストは、メニューバーの「加工」→「加工手順を開く」で加工手順を開くと出ます。表示の設定（設定パネル。Shift+S）とは別の画面です。

## 手順

1. RedRing を起動します（[動かす](./getting_started.md)）。
2. メニューバーの「ファイル」→「読み込み…」で STL ファイルを選ぶか、STL ファイルをウィンドウにドロップして、形状を読み込みます。読み込んだ形状は、表示中の製品形状として加工の対象になります。
3. メニューバーの「加工」→「加工手順を開く」で加工手順を開きます。画面の下に工程リストが出ます。工程の行をダブルクリックして工程の設定のダイアログを開き、工具・加工の条件を入力して「適用」を押します。素材は、工程リストの「手順の設定」で開くダイアログで入力します。
4. 工程リストの「計算」を押します。表示中の製品形状で、ジョブマネージャーが切削シミュレーションを計算します（[動かす](./getting_started.md) の「ジョブマネージャー」）。計算の間も画面は止まらず、工程リストに今の条件の計算の状態（計算待ち・計算中・計算完了・計算失敗）を出します。
5. 計算が終わったら「切削シミュレーション表示」を押して、今の条件で正常に終わった切削シミュレーションのうち最も新しいものを取り込んで表示します。もう一度押すと、表示を閉じて、製品形状と CL の表示に戻ります。条件または表示中の製品形状を変えた後は、計算し直すまで取り込めません。

`Shift+L` は「切削シミュレーション表示」と同じ操作です（加工手順を開いている間だけ）。

取り込みに成功すると、以下が表示されます。

- 製品形状と素材の面、ToolPath ライン、工具ライン
- 左上の進捗バー
- ウィンドウタイトル上の現在フレーム情報

取り込んでも、カメラ（向き・拡大）は変えません。条件を変えて取り込み直しても、同じ所を見比べられます。カメラを形状に合わせ直すときは `r` を押します（表示中の製品形状がない場合だけ、取り込んだときに素材に合わせます）。

## 操作

### 加工手順を開く・閉じる（「加工」）

| 「加工」の項目 | キー | 内容 |
|---|---|---|
| 加工手順を開く | | 加工手順を開き、画面の下に工程リストを出します。開いている間は、選んだ工程の CL を製品形状に重ねて表示し、工程リストを出している間は、計算の状態を読みます |
| 加工手順を閉じる | | 加工手順を閉じます。工程リストと、CL の表示・切削アニメーションを閉じ、それらに使っていたメモリを放します。計算中のジョブは、ジョブマネージャーが続けます |
| 工程リスト | `Shift+M` | 加工手順を開いている間、工程リストの表示・非表示を切り替えます。工程リストを隠しても、加工手順は開いたままです（CL・切削アニメーションはそのままです） |
| 工程の設定 | | 加工手順を開いている間、選んだ工程の設定のダイアログを開きます |
| 手順の設定 | | 加工手順を開いている間、手順の設定のダイアログを開きます |

- 今は、モデルファイルの最初の加工手順を開きます（加工手順を選んで開くのは、後の版です）
- モデルファイルを開いた・新規にしたときは、加工手順を開いていない状態になります
- 加工手順を開いていない間は、`Shift+M`・`Shift+L` を押しても何もしません

### 工程リスト（画面の下）

- 上のツールバーに、手順の名前と、「手順の設定」「工程の設定」（ダイアログを開く）、工程の一覧の操作（「工程追加」「工程複写」「工程削除」「▲」「▼」）を並べます
- その下に、計算の操作のボタンを並べます。「全工程を計算」のほかは、選んだ工程について行います
  - 「計算」: 選んだ工程を計算します。空間モデルに今の条件の CL があり、今の条件の計算が残っていない（ジョブがない・計算失敗・取り消し）ときは、ツールパス生成をせずに、その CL から切削シミュレーションだけを計算します（ジョブマネージャーの結果を消した後や、別の PC でモデルファイルを開いたときなど）。今の条件のツールパス生成の結果がジョブマネージャーに残っていれば、その下に切削シミュレーションを置きます。そうでなければ、ツールパス生成から計算します。どちらから計算を始めたかは、ステータスバーに出します。今の条件の計算が計算待ち・計算中・計算済み（取込済みで、切削シミュレーションの結果があるものを含む）の工程では押せません（同じ計算を重ねないため）。工程の行を選ぶと、その状態で次にできることを、ステータスバーの右に出します（計算が進んでいる・結果を取り込める・CL 取込済みで切削シミュレーションを表示できる・CL 取込済みで切削シミュレーションを計算できる）。状態が分からないときは押せ、押したときに状態を読み、計算待ち・計算中・計算済みなら計算を始めずに、そのことをステータスバーに出します
  - 「再計算」: 選んだ工程の空間モデルの CL を消して、ツールパス生成から計算し直します。その工程の切削アニメーションを表示していれば閉じます（計算を始められなかったときは、CL を消しません）。今の条件の計算が計算中のときは、その計算を取り消して計算し直します（取り消した計算は、ジョブマネージャーの一覧に「取り消し」として残ります）。計算待ちのときは押せません（計算待ちの計算は、まだ始まっていないため、今の条件で最初から計算します）
  - 「全工程を計算」: 手順のすべての工程を、加工の順に計算します。先にすべての工程の条件を確かめ、誤りのある工程があれば、どの工程も計算せずに、その工程の名前と理由を出します。今の条件の計算が計算待ち・計算中・計算済みの工程は、計算し直しません（計算の状態を読めないときは、どの工程も計算せず、そのことを出します）。計算する工程ごとに、「計算」と同じく、切削シミュレーションだけを計算するかを決めます
  - 「CL 取込」: 選んだ工程の、今の条件で正常に終わったツールパス生成の CL だけを、空間モデルに取り込みます。切削アニメーションは開きません。切削シミュレーションの計算が終わる前でも取り込めます
  - 「切削シミュレーション表示」: 選んだ工程の、今の条件で正常に終わった切削シミュレーションを取り込んで表示し、その CL も空間モデルに取り込みます。表示している間はボタンに選んだ印が付き、もう一度押すと、切削アニメーションを閉じて（メモリを放します）、製品形状と CL の表示に戻ります。カメラは動かしません
  - 「ジョブマネージャーを開く」: ジョブマネージャーのウィンドウを開きます
  - 最後の操作（計算・取り込み）の結果は、画面の下のステータスバーに出します。選んだ工程の今の条件の計算の状態は、工程の表の「状態」の列に出します（1 秒ごとに読み直します）。空間モデルの CL が今の条件の結果か（まだ取り込んでいない・今の条件の結果・前の条件の結果）は、ステータスバーの 📋 で開く一覧で見られます
  - 選んだ工程か手順の条件に誤りがあると、「計算」「再計算」を押せなくなります。押せないボタンにマウスを乗せると、誤りの文を出します（ステータスバーの 📋 の一覧と、設定のダイアログの直す欄の下にも出します）
  - 今は、どの工程の切削シミュレーションも手順の素材から始めます（前の工程の後の素材から始めるのは、後の版です）
- 工程の表に、加工手順の工程を加工の順に並べます。列は、順番・名前・加工の段階・加工の種類・工具・状態です。状態は、計算の状態（未計算・計算待ち・計算中・計算済み・取込済み・計算失敗・取り消し・状態不明）です。「取込済み」は、空間モデルの CL が今の条件の結果の工程です。「状態不明」は、ジョブマネージャーが動いていない・見つからないため、計算の状態が分からない工程です（加工手順を開いただけでは、ジョブマネージャーを起動しません。CL が今の条件の結果の工程は「取込済み」と出します）。ジョブマネージャーが動いていない・見つからないことは、ステータスバーにも出します。「計算」「全工程を計算」は、ジョブマネージャーを起動し、計算の状態を読んでから計算を始めます
  - 行を押すと選び、ダブルクリックすると工程の設定のダイアログを開きます。右クリックで、工程の設定・計算・再計算・CL 取込・切削シミュレーション表示・工程追加・工程複写・工程削除・前へ・後へのメニューを出します（右クリックした行を選んでから出します）
  - 工程を選ぶと、その工程の空間モデルの CL を、製品形状に重ねて表示します（ジョブマネージャーには問い合わせません）。今の条件の結果でない CL は灰色で表示します。CL を取り込んでいない工程では、CL を表示しません
  - CL は、加工手順を開いている間だけ表示します。モデルファイルを開いただけでは表示せず、加工手順を閉じると消します
  - 切削アニメーションは、取り込んだ工程を選んでいる間だけ表示します。ほかの工程を選ぶと、切削アニメーションを閉じて、その工程の CL を表示します（もう一度見るときは「切削シミュレーション表示」を押します）
  - 「工程追加」: 選んだ工程のすぐ後に、新しい工程（既定の条件）を加えます
  - 「工程複写」: 選んだ工程と同じ条件の工程を、すぐ後に加えます（計算の結果と取り込んだ CL は受け継ぎません）
  - 「工程削除」: 選んだ工程と、その工程の取り込んだ CL を消します。工程が 1 つだけのときは押せません
  - 「▲」「▼」: 選んだ工程を、加工の順で前・後へ動かします
- 工程リストの上の境界をドラッグすると、高さを変えられます

### 条件の編集（工程の設定・手順の設定のダイアログ）

- 条件は、ダイアログで編集し、「適用」を押すまで工程・手順に入れません。入力欄を触っただけでは、工程は再計算待ちになりません。「キャンセル」・ダイアログの閉じるボタン・`Esc` で、編集を捨てて閉じます（入力欄を編集している間の `Esc` は、入力欄を離れるだけです）
- ダイアログはタイトルの行で動かせます。開いている間も、カメラの操作（回転・移動・拡大、`r`・`t`・`f`・`e`）、切削アニメーションの再生・コマ送り、設定パネルは使えます
- 開いている間は、工程リストは押せません。「加工」の項目、「ファイル」の終了のほかの項目（保存を含みます）、ファイルの操作のキー（`Ctrl+N` など）、`Shift+M`・`Shift+L`、ファイルのドロップも受けません
- 工程の設定では、「適用」「キャンセル」の右の「適用と同時に計算する」を選ぶと、適用した後に、その工程を計算します（選んだ状態は、次に開いたときも同じです）。選んでいる間は、条件に誤りがあると「適用」を押せません
- 条件の誤りは、適用する前から、直す欄の下に赤い文字で出します

### 工程の設定のダイアログ

- 選んだ工程の条件を編集します。ダイアログの題に、工程の名前を出します
- 頁「加工条件」: 名前（入力欄の外を押すか `Enter` で決まります）、加工の段階（荒・中・仕上げ）、加工の種類（今はスキャン加工だけ）、工具（種類・工具径・工具長）、スキャン加工の条件（送り方・ピックフィード・送り・走査線の角度・工具の移動範囲）。ツールパス生成のトレランス（0.001 mm）は表示だけで、変えられません
- スキャン加工の条件の欄に、平らな面で隣り合うパスの間に残る山の高さ（カスプハイト）の上限を表示します（パスの間は、加工範囲を等分するため、ピックフィード以下になります）。ボールエンドミルは工具径とピックフィードで決まり（例: 工具径 10 mm・ピックフィード 2 mm で 0.1010 mm）、フラットエンドミルは 0 です。傾いた面では変わるため、目安の値です。ピックフィードが工具径を超えるときは表示しません
- 頁「加工領域・加工対象」: 加工の対象（表示中の製品形状の面。手順のすべての工程で同じです）と、加工領域（今は加工の対象の XY の範囲。範囲を指定するのは、後の版です）
- 適用した条件に誤りがあると、工程リストの「計算」「再計算」を押せなくなります。例: 精度がツールパス生成のトレランスより細かい、素材の大きさに対して精度が細かすぎる（計算できる最も細かい精度を表示します）、ピックフィードが工具径を超える（工具径を表示します）。誤りの文は表示の言語（日本語・英語）で出します。ジョブの実行や結果の取り込みなど、条件では直せない失敗も、理由を表示の言語で出します。詳しい理由は、ログ（英語）に残します
- 取り込むと（CL 取込・切削シミュレーション表示）、計算した CL（ツールパス）を空間モデルに取り込み、モデルファイルに保存できるようになります（保存していない変更になります）。条件を変えると、空間モデルの CL は「前の条件の結果」になり、今の条件の結果を取り込むと置き換わります
- 選んだ工程の切削アニメーションを表示している間は、ダイアログの下の「表示中の結果の条件」に、その計算に使った条件（工具・加工・トレランス・素材の大きさ・精度）を表示します

### 手順の設定のダイアログ

- 手順の名前（表示だけ）と、素材（余裕・精度）を編集します。素材は、手順のすべての工程で同じです。変えると、手順のすべての工程が再計算待ちになります
- 素材の誤りは、欄の下に赤い文字で出します

### 時点の移動と再生

- `k`: コマ送りの移動量だけ経路に沿って進んだフレームへ進みます（最後のフレームからは先頭へ）
- `j`: コマ送りの移動量だけ経路に沿って戻ったフレームへ戻ります（先頭のフレームからは最後へ）
- コマ送りの移動量は、設定パネル（Shift+S）の表示タブの「コマ送り」で mm の数値で入力します。取り込むたびに、ツールパスの全長の 1/100（1 回の送りが進捗バーの約 1%）に戻ります。「初期値に戻す」ボタン（初期値の mm を併記）で、取り込んだ直後の値に戻せます。移動量が 1 フレームの間隔より短い場合（0 を含む）は、1 フレームずつ移ります
- `.` / `,`: 工具を次 / 前の区間の端点（ツールパスの直線の区間の始点・終点）へ移します。素材は、その端点の手前で最も近いフレームの状態を表示します（フレームは工具と格子から決めた間隔で記録するため、端点ちょうどの素材の形はありません）。端点に置いている間は、ウィンドウタイトルに工具の端点の番号と、表示している素材のフレームを表示します。`k`・`j`・スクラブ・自動再生でフレームが変わると、工具はフレームの位置に戻ります
- 左上の進捗バーを左ドラッグ: 任意フレームへスクラブします
- `Space`: 自動再生と一時停止を切り替えます。1 倍では、工具が経路に沿って毎秒 1 m 進みます（どのワークでも、同じ倍率なら工具の速さは同じです）
- `Shift+J`: 自動再生を停止して先頭フレームへ戻します
- `+` / `-`: 再生速度を 2 倍・半分にします（0.25 倍から 32 倍まで）。現在倍率はウィンドウタイトルに表示されます

取り込む前に `k`・`j`・`Space` を押すと、取り込まれていない旨をログへ表示します。

前へ進む場合も戻る場合も、変化した部分の素材の面だけを差し替えます。最初のほうへ大きく戻す場合（末尾で `Space` を押して最初から再生する場合など）は、初期の素材から面を作り直します。

自動再生は、描画が間に合わない区間ではコマを飛ばさずに再生がゆっくりになります。倍率を上げて 1 回の描画で工具が工具の大きさより大きく進むと（たとえば φ10 の工具では 4 倍以上）、画面の描き直しが工具の動きに追いつかず、残像で工具が複数あるように見えます。工具の線は常に描きます。

### 削り込み・削り残しの色分け

最後のフレームでは、素材の面を、製品形状との比較で色分けします（既定は入）。

| 色（既定） | 意味 |
|---|---|
| 赤 | 削り込み（製品形状の内側へ、ツールパス生成のトレランスより深く削った所） |
| 緑 | トレランスの中（製品形状からの距離がトレランス以内） |
| 青 | 削り残し（製品形状の外側へ、トレランスより離れた所） |
| 素材の色 | 比べていない所（削っていない素材の外周など） |

- トレランスは 0.001 mm のため、ボールエンドミルのパスの間の山（カスプハイトの分）は削り残しの色になります。緑は、パスの中心の近くなど、製品形状に届いた所に出ます
- 色は素材の格子の間隔ごとに決めるため、色の境は格子の間隔（精度 0.05 mm で約 1.4 mm）ほどずれることがあり、それより細い削り込みは見落とすことがあります
- 色分けの入・切と 3 つの色は、設定パネル（Shift+S）の表示タブの「切削アニメーションの色」で選び、「設定を反映」で反映します。最後のフレーム以外では、素材の色で描きます

## 取り込み直後に確認するポイント

- ウィンドウタイトルが `Snapshot 1/N` 形式に変わる
- 左上に進捗バーが出る
- `k` / `j` でフレーム番号と残体積が変化し、素材の面が削れていく
- `w` でソリッド表示とワイヤーフレーム表示が切り替わる
- `v` でツールパスの線、`Shift+V` で工具の線が消え、もう一度押すと元に戻る
