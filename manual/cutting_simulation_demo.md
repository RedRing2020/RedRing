# 切削シミュレーション 操作

製品形状（STL）を取り込み、表示中の製品形状を加工の対象として切削シミュレーションを投入・実行し、結果を製品形状に重ねて時系列で確認します。

## 現在の対象範囲

- 対応工具: フラットエンドミル、ボールエンドミル（φ10・刃長 50）
- 加工: 3 軸の走査線加工（ステップオーバー 2 mm・サンプル間隔 1 mm）
- 素材: 製品形状を囲む箱に、XY の周りと上に 5 mm の余裕を足した直方体
- スナップショット操作: コマ送り、巻き戻し、スクラブ、自動再生
- 表示モード: ソリッド表示、ワイヤーフレーム表示

工具・加工の条件は、工具ライブラリと条件の入力の画面ができるまでの初期値です。

## 手順

1. ワークスペースのルートで `cargo run` を実行します。
2. STL ファイルをウィンドウにドロップして、製品形状として取り込みます。
3. `Shift+B`（ボールエンドミル）または `Shift+F`（フラットエンドミル）を押して、表示中の製品形状で切削シミュレーションを投入します。
4. `Shift+R` を押して、キューにあるジョブを実行します（ジョブマネージャーができるまでの操作です。実行が終わるまで画面は止まります）。
5. `Shift+L` を押して、正常に実行済みの切削シミュレーションのうち最も新しいものを取り込みます。

取り込みに成功すると、以下が表示されます。

- 製品形状と素材の面、ToolPath ライン、工具ライン
- 左上の進捗バー
- ウィンドウタイトル上の現在フレーム情報

## 基本操作

### 投入・実行・取り込み

- STL ファイルをドロップ: 製品形状として取り込みます
- `Shift+B` / `Shift+F`: 表示中の製品形状で投入します（ボール / フラット）
- `Shift+R`: キューにあるジョブを実行します
- `Shift+L`: 最も新しい切削シミュレーションを取り込んで再生できるようにします
- `h`: 利用可能なキー操作をログへ表示します

### スナップショット移動

- `k`: 次のフレームへ進みます
- `j`: 前のフレームへ戻ります
- 左上の進捗バーを左ドラッグ: 任意フレームへスクラブします
- `Space`: 自動再生と一時停止を切り替えます
- `Shift+J`: 自動再生を停止して先頭フレームへ戻します
- `+` / `-`: 再生速度を変更します。現在倍率はウィンドウタイトルに表示されます

取り込む前に `k`・`j`・`Space` を押すと、取り込まれていない旨をログへ表示します。

前へ進む場合は変化した部分の素材の面だけを差し替え、戻る場合は素材の面を作り直します。

### 表示切替

- `w`: ソリッド表示とワイヤーフレーム表示（三角形の辺）を切り替えます

### カメラ操作

- `Ctrl+左ドラッグ`: 回転
- `Ctrl+中ドラッグ`: パン
- `Ctrl+右ドラッグ` または `Ctrl+ホイール`: ズーム

## 取り込み直後に確認するポイント

- ウィンドウタイトルが `Snapshot 1/N` 形式に変わる
- 左上に進捗バーが出る
- `k` / `j` でフレーム番号と残体積が変化し、素材の面が削れていく
- `w` でソリッド表示とワイヤーフレーム表示が切り替わる

## 制約

- 加工の対象は表示中のすべての製品形状です（面の選択は後続の対応です）
- 投入・実行・取り込みの選択の画面はまだなく、取り込みは最も新しい結果だけです
- 素材の色は切削シミュレーション用のシェーディング色設定を使います（取り込んだ後の色の変更は、次の取り込みから反映されます）

## 表示項目（現時点の整理）

この節は、デモ画面に表示する加工サマリの最小セットを定義します。

必須（Phase 1b で表示対象）:

- 全体の距離（mm）
- 切削時間（推定）
- 各軸の Min / Max（X / Y / Z）
- 5軸時の回転軸 Min / Max（A / B / C など、存在する軸のみ）

算出ルール（現時点）:

- 全体の距離は ToolPath の総距離を使用する
- 切削時間は `切削時間[分] = 全体の距離[mm] / 平均送り速度[mm/min]` で算出する
- 現在のサンプル ToolPath は送り速度固定のため、平均送り速度は固定値で扱う
- 可変送り速度ジョブに対する加重平均方式は後続改善で対応する

推奨（表示できると有用）:

- 切削距離 / 早送り距離の内訳
- 切削時間 / 非切削時間の内訳
- 現在フレーム時点の累積距離と進捗率
- ワーク包絡の Min / Max（加工範囲確認用）

追加合意項目（この時点で必要）:

- 現在フレームの累積時間と残り推定時間
- 現在セグメント種別（Cutting / Rapid / Approach / Retract / PassRetract）
- 工具接触中フラグ（切削中か空走中か）
- 除去体積率（初期体積比の進捗）

注記:

- 3軸デモでは回転軸項目は `N/A` 表示でよい
- 5軸 ToolPath では姿勢データから回転軸レンジを算出する
