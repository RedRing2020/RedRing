# 切削シミュレーション デモ操作

切削シミュレーションは、VoxelOctree を用いたワーク除去結果を時系列スナップショットとして確認するデモです。
現在のデモはフラットエンドミル/ボールエンドミルの両方を対象にしており、ワイヤー表示とソリッド表示を切り替えながら確認できます。

## デモの目的

- ToolPath に沿ってワークが除去される過程をフレーム単位で確認する
- 同じスナップショット列をワイヤー表示とソリッド表示で比較する
- 切削シミュレーションの開始手順と最低限の操作系を固定する

## 現在の対象範囲

- 対応工具: フラットエンドミル、ボールエンドミル
- スナップショット操作: コマ送り、巻き戻し、スクラブ
- 表示モード: ワイヤー表示、ソリッド表示
- 入力データ: サンプル ToolPath / サンプル切削シミュレーション結果

未対応の項目は以下です。

- 自動再生
- 再生速度変更
- ボクセル除去精度（Octree `max_depth`）のデモ操作中変更

## 起動手順

1. ワークスペースのルートで `cargo run` を実行します。
2. アプリのウィンドウをアクティブにします。
3. `Shift+B` を押して、切削シミュレーションデモを読み込みます。

読み込みに成功すると、以下が同時に表示されます。

- ToolPath ライン
- ワークの初期状態と除去結果のスナップショット
- 左上の進捗バー
- ウィンドウタイトル上の現在フレーム情報

## 基本操作

### デモ開始

- `Shift+B`: ボールエンドミルの切削シミュレーションデモを開始します
- `Shift+F`: フラットエンドミルの切削シミュレーションデモを開始します
- `p`: ToolPath のみを表示します
- `h`: 利用可能なキー操作をログへ表示します

### スナップショット移動

- `k`: 次のフレームへ進みます
- `j`: 前のフレームへ戻ります
- 左上の進捗バーを左ドラッグ: 任意フレームへスクラブします

`k` と `j` を最初に押した時点で、まだスナップショット列が読み込まれていなければデモを自動読込します。

### 表示切替

- `w`: ワイヤー表示とソリッド表示を切り替えます

ワイヤー表示では Octree ベースのフレームを確認し、ソリッド表示ではメッシュ化されたワークと工具オーバーレイを確認します。

### カメラ操作

- `Ctrl+左ドラッグ`: 回転
- `Ctrl+中ドラッグ`: パン
- `Ctrl+右ドラッグ` または `Ctrl+ホイール`: ズーム

## 操作の見え方

### ワイヤー表示

- スナップショットごとの Octree ワイヤーフレームを表示します
- 除去の進行を輪郭ベースで軽く確認したい時に向いています

### ソリッド表示

- スナップショットごとのメッシュ化ワークを表示します
- ToolPath ラインと工具ラインを重ねて確認できます
- ワーク色は切削シミュレーション用のシェーディング色設定を使います

## 開始直後に確認するポイント

デモ開始後は以下を確認すると、正常にロードされたか判別しやすくなります。

- ウィンドウタイトルが `Snapshot 1/N` 形式に変わる
- 左上に進捗バーが出る
- `k` / `j` でフレーム番号と残体積が変化する
- `w` でワイヤー表示とソリッド表示が切り替わる

## 制約

- 現在のデモはサンプルデータの可視化であり、任意 CAM ジョブの再生 UI ではありません
- 自動再生は未実装のため、時系列確認はコマ送りまたはスクラブで行います
- ボールエンドミルは `Shift+B` で実行できます
- ボクセル除去精度は `OctreeVisualizationSettings.max_depth` に依存し、現行デモでは実行時 UI から変更できません（既定値は 4）

## 表示項目（現時点の整理）

この節は、デモ画面に表示する加工サマリの最小セットを定義します。

必須（Phase 1b で表示対象）:

- 全体の距離（mm）
- 切削時間（推定）
- 各軸の Min / Max（X / Y / Z）
- 5軸時の回転軸 Min / Max（A / B / C など、存在する軸のみ）

算出ルール（現時点）:

- 全体の距離は ToolPath の総距離を使用する
- 切削時間は `切削時間[分] = 全体の距離[mm] / 平均送り速度[mm/min]` で算出する
- 現在のサンプル ToolPath は送り速度固定のため、平均送り速度は固定値で扱う
- 可変送り速度ジョブに対する加重平均方式は後続改善で対応する

推奨（表示できると有用）:

- 切削距離 / 早送り距離の内訳
- 切削時間 / 非切削時間の内訳
- 現在フレーム時点の累積距離と進捗率
- ワーク包絡の Min / Max（加工範囲確認用）

追加合意項目（この時点で必要）:

- 現在フレームの累積時間と残り推定時間
- 現在セグメント種別（Cutting / Rapid / Approach / Retract / PassRetract）
- 工具接触中フラグ（切削中か空走中か）
- 除去体積率（初期体積比の進捗）

注記:

- 3軸デモでは回転軸項目は `N/A` 表示でよい
- 5軸 ToolPath では姿勢データから回転軸レンジを算出する
