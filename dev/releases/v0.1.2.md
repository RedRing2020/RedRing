# RedRing v0.1.2（プレビュー）

## Release Information

- Version: `v0.1.2`
- Release Date: 2026-11-06
- Target Branch: `main`
- Related Milestone: なし（`dev/architecture/RELEASE_VERSION_PLAN.md` 2.1）
- Related PRs: #1103（ヘルプのメニュー・ステータスバー・コンソールを開かない）、#1105（画面の言語の切り替えと設定のファイル）、#1107（ログ・エラーの文の英語化）、#1108（失敗の理由の多言語化）

## Summary

画面まわりを使いやすくした版です。操作の一覧とバージョンの情報を「ヘルプ」のメニューから開けるようにし、操作の結果や失敗の理由を画面の下のステータスバーに出すようにしました。画面の文言は「表示」→「言語」で日本語・英語を切り替えられ、選んだ言語は次の起動でも使います。リリースのビルドはコンソールのウィンドウを開かなくなりました。ログは、画面の言語にかかわらず英語で書きます。

## Highlights

### Added

- 「ヘルプ」のメニュー: 「操作の一覧」（`F1`・`h` キーでも開閉）でキーとマウスの操作の一覧を、「バージョンの情報」で版・ログのファイルの場所・マニュアルへのリンクを出す（#1056）
- 画面の下のステータスバー: 形状の読み込み・投入・実行・取り込みの結果と、操作できなかったときの理由を出す。注意は黄色、失敗は赤（#1056）
- 「表示」→「言語」で、画面の文言を日本語・英語に切り替える。選んだ言語は利用者ごとの設定のファイル（Windows では `%APPDATA%\RedRing\settings.json`）に保存する（#1104）

### Changed

- リリースのビルドはコンソールのウィンドウを開かない。パニックと GPU のデバイスが失われたときは、ログのファイルの場所を書いたエラーメッセージの画面を出して終わる（#1056）
- `h` キーは、キーの一覧をログに出す代わりに、操作の一覧のウィンドウを開閉する（#1056）
- 画面に出す失敗の理由を、エラーの種類ごとの文言にし、選んだ言語で出す（#1106）
- ログ・エラーの文・コンソールへの出力・パニックの文を英語に統一する（#1106）
- 加工条件のウィンドウ・設定パネル・操作の一覧は、画面に収まらないときにスクロールする

### Fixed

- 中身が壊れた STL が、三角形のない形状として「読み込みました」になっていた。読み込みの失敗にする
- 起動直後のウィンドウのタイトルが「winit window」だった。「RedRing」にする
- STL のファイルを読めない（ない・許可がない・ほかのアプリが使っている）ときに、「壊れているか、形式が違う」と出ないようにする
