# RedRing v0.1.3（プレビュー）

## Release Information

- Version: `v0.1.3`
- Release Date: 2026-11-07
- Target Branch: `main`
- Related Milestone: なし（`dev/architecture/RELEASE_VERSION_PLAN.md` 2.）
- Related PRs: #1145（Windows の配布物・チェックサム・SBOM・ビルドの出所の証明）、#1146（マニュアルの英語版）、#1136（走査線の角度）、#1135（立壁の縁と谷の削り残しの修正）、#1141（細かいメッシュでのツールパスの計算の高速化）、#1117（終了のときの異常終了の修正）

## Summary

ソースからビルドしなくても試せるようにした版です。リリースに Windows 用の配布物（zip）を添え、チェックサム・SBOM・GitHub のビルドの出所の証明で、受け取った配布物を確かめられるようにしました。マニュアルの英語版を足しました。スキャン加工では、走査線の角度を指定でき、立壁の上の縁と谷での削り残しを直し、工具の半径に比べて細かいメッシュでのツールパスの計算を大幅に速くしました。

## Highlights

### Added

- リリースに Windows 用の配布物（`redring-v0.1.3-windows-x86_64.zip`）を添える。CI でタグのソースからビルドし、SHA-256 のチェックサム（`SHA256SUMS.txt`）・SBOM（CycloneDX）・GitHub のビルドの出所の証明（`gh attestation verify` で確かめる）を付ける（#1086）
- 利用者向けマニュアルの英語版（https://redring2020.github.io/RedRing/en/）。「ヘルプ」→「バージョンの情報」のマニュアルへのリンクは、画面の言語のマニュアルを開く（#1143）
- スキャン加工の走査線の向きを、X 軸からの角度（既定は 0°）で指定する。急な壁を横切る向きに走査線を引けば、壁の上の削り残しを減らせる（#1128）

### Changed

- 工具の半径に比べて細かいメッシュで、ツールパスの計算を速くする（例: 5.6 万三角形で 29 s → 0.5 s、52 万三角形で 1,085 s → 4.1 s）（#1139）
- 逆オフセット形状のデバッグ用の表示は、カメラを変えず、取り込んだ切削シミュレーションのツールパスの線を重ねる（#1122）

### Fixed

- スキャン加工のパスが、立壁の上の縁と下の谷で CL の面から大きく離れ、削り残していた（工具 φ10 で最大約 4 mm）。パスがトレランスの中に収まるように、谷と段差に点を足す（#1124）
- 終了するときに、ときどき 0xc0000409 で異常終了していた（#1116）
- 起動したときにウィンドウが一瞬白く表示されていた（#1113）
- 切削アニメーションの表示中にデバッグ用の表示をすると、通常の表示に戻せなかった（#1120）
- 逆オフセット形状の表示で動かしたカメラが、通常の表示に戻すと元に戻っていた（#1126）

## Breaking Changes

## English

### Summary

This release lets you try RedRing without building it from source. Releases now include a Windows package (zip), and you can check the package with SHA-256 checksums, an SBOM, and GitHub build provenance. An English version of the manual is added. In scanline machining, the scan angle can be specified, uncut stock at the top edges of walls and in valleys is fixed, and toolpath calculation on meshes that are fine compared with the tool radius is much faster.

### Highlights

Added:

- A Windows package (`redring-v0.1.3-windows-x86_64.zip`) attached to the release. It is built by CI from the tag source, with SHA-256 checksums (`SHA256SUMS.txt`), an SBOM (CycloneDX), and GitHub build provenance (check with `gh attestation verify`)
- The English user manual (https://redring2020.github.io/RedRing/en/). "Help" → "About" opens the manual in the screen language
- The scanline direction can be set by an angle from the X axis (default 0°). Scanlines crossing steep walls leave less uncut stock on the walls

Changed:

- Faster toolpath calculation on meshes that are fine compared with the tool radius (for example 29 s → 0.5 s with 56,000 triangles, and 1,085 s → 4.1 s with 520,000 triangles)
- The debug view of the inverse offset shape keeps the camera and draws the toolpath lines of the imported cutting simulation over it

Fixed:

- Scanline paths left the CL surface at the top edges of walls and in valleys and left uncut stock (up to about 4 mm with a D10 tool). Points are added at valleys and steps so that the path stays within the tolerance
- The app sometimes ended with 0xc0000409 when quitting
- The window flashed white at startup
- A debug view shown during the cutting animation could not go back to the normal view
- A camera moved in the inverse offset shape view was reset when going back to the normal view

### Breaking Changes

- None (data and operations are the same as v0.1.2. The Machining Conditions window has a new scan angle field, and the default 0° gives the same result as before)

### Known Issues

- The known issues of v0.1.2 remain (except that the manual was Japanese only and there was no executable package)
- The package is for Windows only. The executable does not have a code signature yet, so SmartScreen shows a warning the first time you start it
- The screen stops while a calculation runs (to be handled by the job manager)
