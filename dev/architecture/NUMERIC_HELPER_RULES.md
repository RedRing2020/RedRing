# Numeric Helper Rules

最終更新: 2026-10-10

## 目的

範囲判定・角度の正規化・周期範囲の判定のような汎用ヘルパーの配置・命名・追加の判断基準を定め、利用側の用語に合わせた同じロジックのラッパーや別名が増えることを防ぐ。

## 配置

| 種類 | 配置 | 理由 |
| --- | --- | --- |
| 数値・角度だけで完結する判定・変換（閉区間・角度の正規化・周期範囲） | `analysis` | 幾何形状にも業務にも依存せず、`geo_*` と業務クレート（`cam_core` 等）の両方から使う |
| 幾何形状の型（点・ベクトル・方向・AABB 等）を扱うヘルパー | `geo_core` | 幾何形状クレートの共通基盤 |
| 形状間の演算（衝突・交差・距離） | `geo_algorithms` | 演算の正本。配置は `GEO_ALGORITHMS_MODULE_STRUCTURE_RULES.md` に従う |
| 業務の意味付け（軸・送り速度・加速度等の制約） | 業務クレート（`cam_core` 等） | 汎用ヘルパーを呼び、意味付けは利用側で持つ |

## 現在の汎用ヘルパー

| ヘルパー | 内容 |
| --- | --- |
| `analysis::is_within_closed_range(value, min, max, tolerance)` | 閉区間 `[min, max]` に許容誤差付きで含まれるか。有限でない値と `min > max` は `false` |
| `analysis::Angle::normalize` / `normalize_signed` | `[0, 2π)` / `(-π, π]` への正規化 |
| `analysis::Angle::is_equivalent` | 周期を考慮した角度の同値判定 |
| `analysis::AngleRange` | 開始角から反時計回りに `span`（`0 < span <= 2π`）進む角度範囲。0° 跨ぎと全周を場合分けなしに表し、`contains(angle, tolerance)` で両端を含めて判定する |

## 命名

- 汎用ヘルパーの名前・doc コメントに業務用語（送り速度・軸トラベル等）や物理単位（`_mm`・`_deg_per_min` 等）を入れない。意味付けは利用側の変数名・エラー型で表す
- 同じ処理の別名を公開しない（利用側の用語に合わせた名前・「設計側の用語に合わせた公開名」を追加しない）
- 角度は `Angle<T>` で受け渡し、度・ラジアンの区別を名前で表さない。度で値を持つ利用側は境界で `Angle::from_degrees` に変換する

## 追加の判断基準

新しいヘルパーを追加する前に、次を確認する。

1. 既存のヘルパー（上表）で表現できないか
2. 既存のヘルパーを呼ぶだけのラッパー・別名になっていないか
3. 業務の意味（単位・用途）を含んでいないか。含む場合は利用側のクレートに置く
4. 判定結果に理由（範囲外の種類等）が必要か。呼び出し側が使わない場合は `bool` で返す
5. 有限でない入力と範囲の端の扱い（両端を含む）を doc コメントとテストで明示しているか

## 周期範囲の表現

- 周期方向の範囲は `(start, span)`（反時計回りを正、`0 < span <= 周期`）で表す。`(min, max)` で表すと 0° 跨ぎと全周に場合分けが必要になる
- 下限・上限から作る場合は `AngleRange::from_ccw_bounds` を使い、下限 > 上限は 0° 跨ぎ、差が周期の正の整数倍は全周とする
- 形状の角度範囲の判定（円弧・楕円弧の `contains_angle` 等）は `AngleRange` に委譲する
