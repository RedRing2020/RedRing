# AI Terminology Glossary (RedRing)

最終更新: 2026-03-26

このファイルは、AIの表記ゆれを防ぐための用語統一リストです。
アーキテクチャ説明・PR説明・コードコメントで共通利用します。

## 基本方針

- Rust文脈では `trait` を優先語とする
- 曖昧語より、型・責務が明確な語を使う
- 既存コードと競合する略語は新規導入しない

## コメント運用

- `// ==================================` 形式の区切り線は新規追加しない
- 交差判定の組み合わせ実装では、コメント過密を避ける
- 構造化はコメントではなく、`mod` 分割と関数抽出で行う
- コメントは意図・制約・理由を優先し、説明過多を避ける

## 用語確認ルール

- コメントと命名規則は、業界で通用する用語を優先する
- 新しい用語を使う前に、既存コード・既存ドキュメント・主要な技術文献の用語を確認する
- 根拠が曖昧なカタカナ語やAI由来の造語は使わない
- 用語判断に迷う場合は、用語集へ追記してから使用する

## 推奨語（Preferred）

- trait定義
- trait実装
- 依存関係
- 互換層
- 移設
- 段階移行
- 表記統一
- 移動範囲（直動軸の説明）
- 旋回範囲（回転軸の説明）

## 非推奨語（Avoid）

- 契約定義
- 契約実装
- トラベル範囲（日本語説明では使用しない）

## 言い換えルール

- 契約定義 -> trait定義
- 契約実装 -> trait実装
- 仕様の契約（一般論） -> 仕様（必要時のみ「契約」を補助語として使用）
- トラベル範囲 -> 移動範囲（直動軸）

## 例

- NG: `BasicCollisionの契約定義を追加`
- OK: `BasicCollisionのtrait定義を追加`

- NG: `契約実装をgeo_algorithmsへ移動`
- OK: `trait実装をgeo_algorithmsへ移動`
