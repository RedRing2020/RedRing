# RedRing 単位系統一仕様

## 基本単位系

RedRing プロジェクト全体で使用する単位系を以下に統一します：

### 長さ

- **基本単位: mm (ミリメートル)**
- すべての座標値、距離、寸法は mm 単位で表現
- 許容誤差も同様に mm 単位で設定

### 角度

- **角度は `analysis` の `Angle` で持つ**（形状の型の角度も `Angle`。角度の許容誤差は、下の「許容誤差」のとおりラジアンの数値）
- `Angle` は中でラジアンを持つ。度からもラジアンからも作れ（`from_degrees`・`from_radians`）、どちらでも読める（`to_degrees`・`to_radians`）
- 外部の値は、その単位のまま `Angle` にする（度で書かれた値は `from_degrees` で作る）
- 画面での表示は度とする

### その他の単位

- 面積: mm² (平方ミリメートル)
- 体積: mm³ (立方ミリメートル)
- 曲率: mm⁻¹ (逆ミリメートル)

## 許容誤差

- 長さの許容誤差は mm、角度の許容誤差はラジアンで表す
- 値と使い分けは、コード（`analysis` の `consts`、`geo_core` の `ToleranceSettings`）と `dev/architecture/GEOMETRIC_TOLERANCE_USAGE_RULES.md` を正本とする（この文書には値を書き写さない）

## 実装指針

### 1. 入力データの変換

- 外部ファイル (STL, STEP, OBJ 等) からの入力データは、長さを mm 単位に変換し、角度は `Angle` にする
- 変換係数:
  - メートル → mm: `* 1000.0`
  - インチ → mm: `* 25.4`
  - フィート → mm: `* 304.8`

### 2. 表示・出力での変換

- UI 表示では用途に応じて適切な単位に変換
  - 大きな寸法: m (メートル)
  - 通常の寸法: mm (ミリメートル)
  - 微細な寸法: μm (マイクロメートル)

### 3. API ドキュメント

- すべての関数、構造体で長さに関わるパラメータには単位をコメントで明記
- 例: `pub fn move_by(&mut self, delta: Vector3D) // delta in mm`

### 4. テストケース

- テストケースでは実際の CAD 作業で使用される現実的な値を使用
- 例:
  - ボルト穴径: 8.0 (8mm)
  - 板厚: 5.0 (5mm)
  - 機械部品サイズ: 100.0 〜 1000.0 (100mm〜1000mm)

## 注意事項

1. **浮動小数点精度**: mm 単位での計算により、f64 の精度内で十分な精度を確保
2. **オーバーフロー防止**: 極端に大きな値 (>1e12 mm = 1,000 km) への対策
3. **アンダーフロー防止**: 極端に小さな値 (<1e-12 mm = 1 pm) への対策
4. **国際化対応**: 将来的にインチ系表示への対応可能性を考慮

---

**重要**: この仕様に従い、すべての新規実装およびリファクタリングを実施すること。
単位系の混在はバグの原因となるため、厳格に統一を維持する。
